Hazard Haul

Sci-fi auto shooter: survive waves of enemies across 5 planets. Die, and it's back to the start.

  • Solo
  • Grade 5 / 5
  • Oct – Dec 2025
  • Unity · C#
  • Metropolia UAS project

What I built

  • The whole game, solo: gameplay, enemy AI, UI, saving, scene flow.
  • MS_Tools, my own reusable Unity package: generic singleton, timers, extensions and editor tools (see below).
  • Generic object pooling for enemies, game objects and audio sources.
  • Timer system hooked directly into Unity's PlayerLoop instead of MonoBehaviour updates.
  • Event-driven architecture with C# delegates for scene switching, UI and saving.
  • Enemy navigation with Unity NavMesh.
  • VFX: modified existing effects and made a few of my own in Shader Graph.

Overtail

Turn-based tactics prototype inspired by Final Fantasy Tactics, with a cast of forest animals.

  • Team of 7
  • ~3 months
  • Unity 6 · C#
  • Metropolia UAS project

My part

  • Input system: one ScriptableObject that wraps Unity's Input System and exposes events for camera, abilities, items and UI. Gameplay input is switched off during enemy turns.
  • Tactics camera with Cinemachine: follows the active unit, free look, zoom, map bounds and a refocus hotkey.
  • Enemy AI foundation: the BaseAction pattern, enemy turn flow and MoveAction. Teammates built the attack and move evaluation on top of it.
  • Repo setup: project structure, Git workflow, and reviewing and merging the team's early pull requests.

Also used: FMOD, A* Pathfinding, URP. My MS_Tools singletons run the core managers.

Unity DOTS RTS

RTS prototype built fully in Unity's Entity Component System, with large numbers of units fighting zombie hordes.

  • In development
  • Solo
  • Entities · Burst · Jobs
  • 23 Burst-compiled ISystems with parallel jobs for movement, targeting and combat.
  • Baked mesh animation stored in BlobAssets, so animation runs without Animators.
  • ECS physics queries for target finding and box selection that connects GameObjects and entities.

Started from a DOTS course and extended from there. Latest: barracks and unit spawning.
